# Sky Luach launcher · לוח השמים

Home-screen page for the [Sky Luach app](https://sky-luach.streamlit.app/). Add it to a phone's or tablet's home screen; the icon then opens the app directly.

The app's address is the one line `var APP_URL` in `index.html`.
